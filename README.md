# 留给艺的一座小站

> 有些回忆不该只剩下一份躺在硬盘里的聊天记录。

这个项目的起点其实很简单：我想把散落在消息、照片、定位和语音里的那些瞬间，重新整理成一个可以慢慢翻看的地方。

它不是为了复刻谁，也不是想让 AI 代替谁。只是有些人认真来过，有些事真实发生过，我舍不得让它们被时间悄悄盖住。所以做了这座小站，留给回忆，也留给以后偶然点开它的自己。

如果你也想整理一段属于自己的故事，可以把这里当作一份参考。技术可以照着用，但请温柔地对待数据，也尊重故事里的每一个人。

## 这里有什么

- **一张回忆地图**：把去过的地方、聊过的地点和还没实现的约定放回地图上。
- **一条时间线**：按时间串起重要的日子、第一次、争吵、和好，以及那些当时觉得普通、后来却很难忘的小事。
- **一本相册**：保留照片原来的样子，点开后能看到时间、描述和相关聊天片段。
- **一些声音**：整理语音、转写文字，也支持在取得同意后进行语音模型实验。
- **一个聊天页面**：根据整理出的表达习惯做成 AI 对话入口。它只是技术实验，不是真实的人，也替代不了真实的人。
- **一组视觉档案**：用来查看、核对和筛选照片识别结果，尽量不让模型替回忆编故事。

## 从一份聊天记录开始

需要准备：

- WeFlow 导出的 `jsonl` 聊天记录；
- 对应的 `media` 文件夹（图片、表情、视频和语音）；
- 可选的 DeepSeek API Key，用于图片识别和聊天模块。

大致流程是：

1. **整理聊天**：解析消息时间、发送者、定位和媒体文件，再按月份梳理事件、地点、称呼与重要片段。
2. **看懂照片**：批量识别图片，并结合前后聊天判断当时在做什么。没有证据的内容就明确写“无法确定”，不替过去添戏。
3. **整理声音**：用 FunASR 转写语音；如果要做 GPT-SoVITS 语音实验，请先确认拥有素材的使用许可。
4. **生成网页**：把地图、时间线、相册、语音和聊天模块放进同一个站点。
5. **部署上线**：检查隐私与路径后，再发布到 GitHub Pages 或其他静态托管平台。

更完整的操作步骤和踩坑记录放在 [SKILL.md](SKILL.md) 里。README 只想先让你明白：这是什么，以及为什么会有它。

## 部署前，请认真看一遍

1. **不要把 API Key 写进源码。** 聊天模块只从浏览器的 `localStorage` 读取。
2. **不要上传原始聊天数据。** `jsonl`、完整 `media`、训练素材和模型权重都不该出现在公开仓库里。
3. **只公开真正愿意公开的内容。** 照片、语音、聊天片段和定位都可能暴露隐私。
4. **检查所有相对路径。** 图片和音频应同时适用于本地打开与网页部署。
5. **确认入口文件。** 本项目默认使用 `main.html`；如果托管平台要求默认首页，请改名为 `index.html`。

## 关于隐私，也关于分寸

聊天记录、照片、声音和 AI 人设都与一个真实的人有关。能做到，不代表什么都应该做。

公开站点前，请先取得当事人的明确同意，并对照片、语音、定位和私人对话做必要的删减或脱敏。语音克隆和 AI 对话必须清楚标明是生成内容，不能拿来冒充本人，更不能用于骚扰、欺骗或传播私密信息。

这个项目只提供整理与展示的方法，不替任何使用者取得素材授权，也不替任何不当使用承担责任。
